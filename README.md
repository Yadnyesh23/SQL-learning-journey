# SQL Learning Journey 

This repository documents my SQL learning using the **SQL Course for Beginners** by Programming with Mosh.  
The course covers core SQL concepts and practical database operations using MySQL.

---

## Course Overview

### 🔹 1. Getting Started
- Introduction to databases and SQL (Structured Query Language)
- Installation of MySQL and MySQL Workbench
- Basic understanding of relational databases

---

### 🔹 2. Database Setup
- Setting up practice databases (SQL Store, Invoicing, etc.)
- Understanding tables, rows, and relationships
- Primary keys and foreign keys

---

### 🔹 3. Retrieving Data
- SELECT, FROM, WHERE
- Logical operators: AND, OR, NOT
- Filtering: IN, BETWEEN, LIKE, REGEXP, IS NULL
- Sorting with ORDER BY
- Limiting results with LIMIT

---

### 🔹 4. Joining Tables
- INNER JOIN
- LEFT JOIN / RIGHT JOIN
- SELF JOIN
- CROSS JOIN
- Joining multiple tables
- USING clause

---

### 🔹 5. Modifying Data
- INSERT (single & multiple rows)
- UPDATE (with conditions & subqueries)
- DELETE statements
- Creating table copies

---

## 🎯 Goal
To build strong SQL fundamentals and apply them through practical queries and mini projects.

---

## 🛠 Tools Used
- MySQL
- MySQL Workbench
- VS Code
