## What I'm Learning

### 1. Getting Started
- What databases are and why they exist
- Relational vs non-relational databases
- Installing MySQL and MySQL Workbench
- Writing your first SQL query

---

### 2. Database Setup
- Setting up practice databases (`sql_store`, `sql_invoicing`, etc.)
- Understanding tables, rows, and columns
- Primary keys and foreign keys
- How tables relate to each other

---

### 3. Retrieving Data
- `SELECT` and `FROM` — fetching data from tables
- `WHERE` — filtering rows based on conditions
- Logical operators: `AND`, `OR`, `NOT`
- Range & list filters: `IN`, `BETWEEN`, `LIKE`, `REGEXP`, `IS NULL`
- Sorting results with `ORDER BY`
- Limiting results with `LIMIT`

---

### 4. Joining Tables
- `INNER JOIN` — rows matching in both tables
- `LEFT JOIN` / `RIGHT JOIN` — include unmatched rows from one side
- `SELF JOIN` — joining a table with itself
- `CROSS JOIN` — every combination of rows
- Joining multiple tables at once
- `USING` clause — shorthand when column names match

---

### 5. Modifying Data
- `INSERT` — adding single and multiple rows
- `UPDATE` — modifying existing rows (with conditions and subqueries)
- `DELETE` — removing rows safely
- Creating copies of tables
